# DriveScope

Drive tester for Windows by Dialsoft LLC (theITguy.com). Tests SSDs, hard drives and USB flash drives – health (S.M.A.R.T.), speed benchmarks, fake-capacity check, secure erase, partition tools, which operating system is on the drive – and prints test labels on a Brother QL label printer for resale.

## Download

**[⬇ Download DriveScope (latest)](https://github.com/Dialsoft/drivescope-releases/raw/main/DriveScope.exe)** — current version: **1.18.1**

- Windows 10 or 11, 64-bit. DriveScope asks for administrator rights because it reads drives directly.
- Save it in a folder you can write to (Desktop, Downloads or `C:\Tools`), not Program Files, so it can update itself.
- It opens in your web browser and keeps running in the system tray (bottom-right of the taskbar).

## Updates

DriveScope checks this page a few seconds after it starts and every 6 hours, and offers new versions with one click (or installs them automatically when idle, if you switch that on). Each update is verified against `DriveScope.exe.sha256` before it installs, and never during a test or erase.
